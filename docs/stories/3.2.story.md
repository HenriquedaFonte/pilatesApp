# Story 3.2 — UI: Campos de Seguro no Cadastro + Perfil Profissional da Professora

**Epic:** 3 — Recibos para Seguro Saúde (PRD-002)
**Status:** Implementada (falta o teste no site; ver docs/PENDENCIAS.md)
**Estimativa:** M (3–5h)
**Tipo:** UI
**Esforço:** medium
**Depende de:** Story 3.1

---

## User Story

**Como** aluno, **quero** informar meu número de apólice e os dados do titular no meu perfil,
**como** professora, **quero** ver/editar esses dados na ficha do aluno e cadastrar meus dados profissionais e minha assinatura,
**para que** os recibos saiam preenchidos.

## Notas de implementação (2026-11-12)
- **AC-4:** a ficha do aluno com "Editar perfil" fica em `src/pages/StudentSummary.jsx` (rota `/teacher/student-summary/:id`, botão "Ver" no card do aluno), não num modal do `TeacherStudents.jsx`. A seção "Seguro saúde" foi posta lá, só para a professora.
- **AC-3:** `InsuranceFields.jsx` é um card com carga (`maybeSingle`) e botão salvar próprios. Quando "Eu sou o titular" está ligado, os campos do outro titular são gravados como `null` (não ficam dados velhos que iriam por engano para um recibo). Campos vazios viram `null`.
- **AC-6:** o arquivo vai para `{teacher_id}/signature.png` se for PNG e `{teacher_id}/signature.jpg` se for JPEG (extensão igual ao tipo real, o que ajuda o gerador de PDF da 3.4 a escolher `embedPng`/`embedJpg`). Trocar de PNG para JPEG apaga o arquivo antigo. A 3.4 deve ler o caminho de `signature_path`, nunca montar o nome.
- Dados profissionais ficam numa aba nova "Dados profissionais" em "Meu perfil" da professora (`src/components/PractitionerCredentialsForm.jsx`).
